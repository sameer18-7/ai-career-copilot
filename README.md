# Career CoPILOT

A modern web application built with React, Vite, and TanStack Router/Query, styled with Tailwind CSS.

## Tech Stack
- **Framework:** React 19
- **Build Tool:** Vite
- **Routing:** TanStack Router
- **Data Fetching:** TanStack Query
- **Styling:** Tailwind CSS 4 + Radix UI Primitives

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Run the development server:**
   ```bash
   npm run dev
   ```
3. **Build for production:**
   ```bash
   npm run build
   ```
