# AI Career Copilot — Starter Build

An end-to-end AI career acceleration platform for students (Resume Analyzer → Skill Gap Analysis → Personalized Learning → Interview Coach → Job Placement).

## 🚀 Features & Pages Included

1. **Landing / Home Page (`/`)**: Hero section with pill badges & floating mockups, University logo strip, 5-step interactive process timeline, product preview, testimonials, pricing teaser, and footer.
2. **Features Overview (`/features`)**: Sticky scroll-spy sub-nav, detailed alternating feature breakdowns with interactive mockups, and side-by-side feature comparison table.
3. **Product Dashboard (`/dashboard`)**: In-app dashboard with metric cards, learning progress area charts (Recharts), recent activity log, skill gap progress breakdown, and top job match cards.
4. **Resume Analyzer (`/resume`)**: PDF drop zone, ATS compatibility gauge, extracted skills/experience tabs, missing keyword suggestions, target role selector, and quick fix checklist.
5. **Skill Gap & Learning Path (`/skills`)**: Visual skill radar chart (You vs. Market Demand), missing skill tags, step-by-step learning roadmap, adaptive quiz widget, and recommended resources.
6. **AI Interview Coach (`/interview`)**: Track setup (Google, Amazon, etc.), live interview session interface with sound wave visualization, feedback metrics, question-by-question review, and interview history.
7. **Job Recommendations (`/jobs`)**: Filterable job matches with match score badges, salary estimates, skill match tags, grid/list view toggle, and search.
8. **Pricing (`/pricing`)**: Monthly/Annual billing toggle, 3-tier pricing cards (Free/Pro/Campus), detailed comparison matrix, and FAQ accordion.
9. **Sign Up & Login (`/signup`, `/login`)**: Modern split-screen authentication screens with social login options.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`) + Custom CSS Design Tokens
- **Routing**: React Router v7 (`react-router-dom`)
- **Icons**: Lucide React
- **Charts**: Recharts v3
- **Typography**: Inter (Google Fonts)

## 🚦 Getting Started

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

Open [http://localhost:5173/](http://localhost:5173/) to view the application in your browser.

### Production Build

```bash
npm run build
```
